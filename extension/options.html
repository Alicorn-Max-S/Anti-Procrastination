Start Helper files

This extension downloads the school Google Docs, Slides and Drive files your Canvas assignments link to, using the school account this Chrome is already signed in to, and sends them to your Start Helper server. It never reads or stores your Google cookies.

The address you open Start Helper at, e.g. http://localhost:8000 or a Cloudflare tunnel URL.

Run python -m app.browser_files key in the Start Helper folder and paste what it prints.

Only needed if this Chrome is signed in to more than one Google account. It picks the school one.

Google Assignments copies. To notice when you open your own copy of a doc from a Canvas assignment, the extension needs to see the address of your Canvas tabs at . It reads only the tab address, nothing on the page.
